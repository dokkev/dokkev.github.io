## 감속기 데이터시트를 모델 파라미터로 읽기

감속기 카탈로그에서 위 표의 항목에 대응하는 값은 다음과 같습니다.

| 데이터시트 항목 | 모델에서 쓰이는 곳 |
| --- | --- |
| 감속비, 입력 측 관성 | 반사 관성 $N^2(J_m + J_{in})$ |
| 정방향·역방향 효율 곡선, 무부하 구동 토크, 역구동 개시 토크 | 마찰 모델과 토크 추정의 효율 |
| 비틀림 강성(구간별 값), 허용 비틀림 | 두 관성 모델의 $K_s$, 공진 주파수 |
| 백래시, lost motion, 히스테리시스 손실 | 방향 전환 모델, 위치 오차 범위 |
| 각도 전달 정밀도 | 주기적인 전달 오차의 크기 |
| 순간 최대 토크, 충격 토크, 출력 베어링 모멘트 용량 | 충돌과 착지 시 하중 한계 |
| 수명과 허용 듀티 | 장시간 실험과 데이터 수집 계획 |

효율, 강성과 lost motion은 측정할 때의 토크, 속도와 온도 조건에 따라 달라집니다. 제조사마다 측정 조건이 다르므로, 서로 다른 제조사의 수치를 비교할 때는 조건이 같은지 먼저 확인해야 합니다.
